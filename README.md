# Radar de Talentos — pasta de trabalho

O projeto principal está em [Radar-Talentos-React-Node](Radar-Talentos-React-Node/README.md). Abra `Radar-Talentos.code-workspace` no VS Code.

- `Radar-Talentos-React-Node/`: desenvolvimento em React e Node.js.
- `Radar-Talentos-React-Node/legado/`: referência do Worker entregue no ZIP, para migração.
- `arquivo/radar-worker-anterior/`: cópia da etapa anterior, preservada com suas configurações e alterações locais. Não é o projeto principal.

Os comandos npm devem ser executados dentro de `Radar-Talentos-React-Node/`.
