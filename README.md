# Radar de Talentos — pasta de trabalho

O projeto principal está em [Radar-Talentos-React-Node](Radar-Talentos-React-Node/README.md). Abra `Radar-Talentos.code-workspace` no VS Code.

- `Radar-Talentos-React-Node/`: desenvolvimento em React e Node.js.
- `Radar-Talentos-React-Node/legado/`: referência consolidada do Worker e suíte de 21 testes de aceitação, para migração.

Os comandos npm devem ser executados dentro de `Radar-Talentos-React-Node/` (ou em `Radar-Talentos-React-Node/legado/` para os testes do legado).
