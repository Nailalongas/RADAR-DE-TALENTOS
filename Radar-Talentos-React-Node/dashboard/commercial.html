Como interpretar

Porte é uma faixa operacional configurada pelo indicador principal da mídia, não uma classificação de cachê. Crescimento compara a mesma conta, métrica e fonte com observações próximas aos limites do período. Ausência de informação não equivale a zero. Para audiência regional, use o mapa de audiência. Para demanda observada em eventos, consulte o catálogo de eventos.
